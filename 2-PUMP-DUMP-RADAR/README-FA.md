# Pump/Dump Radar Lab 🚨

رادار مستقل پمپ/دامپ — پروژهٔ کاملاً جدا از اتوتریدر، بدون هیچ وابستگی runtime مشترک.

## چرا مستقل؟
چون تفاوت ارزهای اسکن پمپ/دامپ (صدها جفت ارز Gate.io) با اتوتریدر باعث lag و کندی متقابل می‌شد.
این پروژه پرت خودش (8790)، استوریج خودش، حلقهٔ اسکن خودش — هیچ‌کدام از دوتا اپ دیگری را کند نمی‌کند.

## اجرا
```bash
cd apps/pump-dump-lab
npm install   # فقط برای تست؛ سرور وابستگی ندارد
npm start     # http://localhost:8790
```

## معماری
- `server.js` — استاتیک + پل یک‌طرفه `POST/GET /api/hot` + `/api/health` (بدون وابستگی، Node خالص)
- `src/js/services/radar.js` — اسکن همهٔ جفت‌های USDT بازار اسپات Gate.io (نرخ اسکن از تنظیمات، پیش‌فرض ۸ ثانیه)
- `src/js/services/ignition.js` — امتیازدهی ورود: جهت رادار ۳۰ + EMA9/21 ۱۸ + انفجار حجم ۲۰ + استریک ۲۲ + پنجرهٔ RSI ۱۰ (≥۷۰ = ورود)
- `src/js/services/paper-broker.js` — پیپر با لوریج ۵x، کارمزد taker دوطرفه، SL=1.4×ATR، TP=1.6R، Breakeven + ترلینگ، خروج قاطع `MAX_HOLD_EXIT`
- `src/js/app.js` — حلقهٔ اصلی: رادار → Ignition فقط روی کشف‌شده‌های غیر WATCH → ورود خودکار Zero-Wait
- `src/js/ui/view.js` + `index.html` + `styles.css` — داشبورد سه‌تبه (رادار/معاملات/تنظیمات)

## پل اختیاری به اتوتریدر (futures-pwa)
اگر در تنظیمات `bridgePublish` روشن باشد، هر اسکن لیست نمادهای داغ را به `/api/hot` خودش POST می‌کند.
اتوتریدر فقط در صورت تنظیم `pumpBridgeUrl` در تنظیماتش این لیست را (بدون block کردن حلقه‌اش) می‌خواند.
**پیش‌فرض هر دو خاموش است** — هیچ ارتباطی برقرار نمی‌شود مگر خودت هر دو را روشن کنی.
