## ۰) 🔬 تحلیل سخت — ردیابی «دادهٔ کدام تایم‌فریم» در هر تصمیم

سؤال اصلی تو: *«معامله را روی کندل یک ساعت باز می‌کند ولی با کندل یک دقیقه می‌بندد»*. کل سیستم را با این عینک بازبینی کردم. نتیجهٔ ردیابی کامل:

### جدول حقیقت: هر تصمیم از کجا داده می‌گیرد؟

| تصمیم | منبع داده | تایم‌فریم | وضعیت |
|---|---|---|---|
| تحلیل سیگنال ورود | `market.candles` بعد از هم‌ترازی | **فقط TF اصلی تنظیمات** | ✅ کنترل‌شده |
| فیلتر تأییدیه ورود (ریز‌کندل) | `microCandles` (۱m/۳m) | TF ریز — **فقط امتیاز ورود، نه خروج** | ✅ فقط ورود |
| SL سخت | قیمت زنده + High/Low کندل **بستهٔ TF اصلی** | قیمتی | ✅ |
| ترلینگ سود شناور | ATR سیگنالِ TF اصلی + highWater قیمت زنده | **TF اصلی** | ✅ |
| برگشت روند (RSI/EMA) | سیگنال تحلیل‌شده روی TF اصلی | **TF اصلی** | ✅ |
| محو مومنتوم (Fade) | کندل‌های بستهٔ TF اصلی | **TF اصلی** | ✅ |
| چرخش روند (Flip) | سیگنال TF اصلی | **TF اصلی** | ✅ |
| MaxHold | ساعت سیستم | مستقل از TF | ✅ |

**بررسی مستقیم کد:** بروکر خروج (`paper-broker.js`) **صفر ارجاع** به `microCandles`/`microTf`/`getKlines` دارد — از نظر فنی امکان «بستن با کندل ۱ دقیقه» وجود ندارد، چون اصلاً به آن داده دسترسی ندارد.

### 🕳️ سوراخ پنهان که پیدا و بسته شد (مهم‌ترین یافتهٔ امروز)

باگ اصلی نسخه‌های قبل در مسیر OKX/Binance مستقیم بود (کندل نیمه‌بسته تحلیل می‌شد — در v2.3 بسته شد). اما تحلیل امروز یک **درِ پشتی** دیگر پیدا کرد:

> پوزیشن، تایم‌فریم ورودش را ذخیره نمی‌کرد. اگر تو یا آقا پسر **وسط معامله تایم‌فریم تنظیمات را عوض کنید** (مثلاً 1h → 1m)، خروج‌های سیگنالی (ترلینگ ATR، برگشت RSI، محو مومنتوم، چرخش روند) ناگهان با دیتای تایم *جدید* محاسبه می‌شدند — یعنی دقیقاً «ورود ۱ساعته، بستن ۱دقیقه‌ای»!

**قفل تایم‌فریم (v2.4):**
1. موقع باز شدن، `tfMs` و `timeframe` روی خود پوزیشن **قفل می‌شود**.
2. در هر اسکن، اگر تایم‌فریم سیگنال تازه با تایم‌فریم ورود فرق داشته باشد:
   - ❌ TREND_FLIP، REVERSAL_RSI، REVERSAL_EMA، MOMENTUM_FADE → **قاطع غیرفعال**
   - ❌ جابه‌جایی استاپ ترلینگ با ATR بیگانه → **ممنوع** (استاپ سر جای قبلی می‌ماند)
   - ✅ فقط محافظت‌های قیمتی مستقل از TF فعال‌اند: SL سخت، بریک‌ایون، MaxHold
3. روی کارت ارز دیده می‌شود: «🔒 ورود روی 1h • تنظیمات الان 1m است → خروج‌های سیگنالی قفل» + رخداد در لاگ (`TF LOCK GUARD`).
4. تست‌های اثباتی (گروه ۱۲): سیگنال مخالف ۹۵ امتیازی از تایم ۱m معاملهٔ ۱h را **نمی‌بندد**؛ دو کندل مخالف ۱m fade نمی‌زند؛ ولی SL قیمتی همچنان قاطع می‌بندد.

### اصلاح دوم: برچسب درست خروج‌ها
قبلاً وقتی استاپِ ترلینگ (بالای ورود) لمس می‌شد، خروج `SL_HARD_STOP` ثبت می‌شد — آمار سود/ضرر را کدر می‌کرد. حالا: استاپِ بالای نقطهٔ ورود = `PROFIT_TRAIL_REVERSED` (بستن سود شناور)؛ فقط استاپِ زیر ورود = `SL_HARD_STOP`.

### اصلاح سوم: متریک «اوج سود و پس‌دادن»
هر معاملهٔ بسته‌شده حالا دو فیلد جدید دارد:
- `peakPnl` — سود خالص در **اوج** (بالاترین قلهٔ highWater/کف lowWater)
- `givebackPct` — چند درصد از اوج را پس دادیم تا نقطهٔ خروج

این دقیقاً ابزار تنظیم `trailAtrMult` است: اگر giveback بالا بود → ترلینگ را سفت‌تر کن؛ اگر خروج‌های زودهنگام زیاد شد → شل‌تر. (مثال تست: peak=11.77، خروج 6.78 → giveback=42.5٪ با trail=1.25×ATR.)

## ۱) 🧮 محاسبهٔ سیگنال — قدم‌به‌قدم با مثال عددی کامل

### زنجیرهٔ اسکن (هر ۵ ثانیه، هر نماد)
```
۱) دریافت کندل TF اصلی → هم‌ترازی روی مرز تایم‌فریم → حذف تکراری → حذف کندلِ در حال تشکیل
۲) گیت تازگی: کندل بستهٔ قدیمی‌تر از ۳×TF؟ → WAIT («⏱ کندل کهنه»)
۳) محاسبهٔ اندیکاتورها روی کندل‌های بسته
۴) امتیازدهی اجماع (جدول پایین) + فرمول پارامتریک تو (در صورت فعال بودن)
۵) امتیاز ≥ minScore؟ → LONG/SHORT + پلن معامله؛ وگرنه WAIT + علت شفاف روی کارت
۶) گیت‌های ورود: ضرر روزانه → سقف پوزیشن → تکرار نماد → Cooldown → فرمول filter
```

### جدول امتیازها (موتور اجماع پیش‌فرض)

| شرط (با مقادیر پیش‌فرض) | امتیاز |
|---|---|
| movePct ≥ 0.45٪ (حرکت ۳ کندل) | همان سمت **+۲۴** |
| oneCandlePct ≥ 0.3٪ (کندل آخر) | همان سمت **+۱۲** |
| volX ≥ 1.8× (حجم ÷ میانگین ۲۷ کندل) | هر دو سمت **+۲۲** |
| شکست سقف/کف ۲۲ کندله | همان سمت **+۲۲** |
| روند ۵ از ۷ کندل هم‌جهت | همان سمت **+۱۰** |
| RSI < 35 → خرید / RSI > 65 → فروش | **+۱۵** |
| EMA9 > EMA21 (یا برعکس) | همان سمت **+۸** |
| بدنهٔ کندل قوی هم‌جهت (> 0.35×ATR٪) | همان سمت **+۱۰** |
| ATR٪ < 0.03 (بازار مرده) | هر دو سمت **−۲۰** |
| استریک ریز‌کندل هم‌جهت (۱m/۳m) | ضریب **×1.15** فقط همان سمت |

### مثال عددی کامل (اعداد واقع‌نما، BTC تایم ۱h)

فرض کن کندل‌های بستهٔ اخیر این‌گونه‌اند و تنظیمات پیش‌فرض:

```
قیمت فعلی: 100,350 | کندل چهارم قبل: 99,200
حجم کندل آخر: 850 | میانگین حجم ۲۷ کندل قبل: 400
ATR(14): 380 (≡0.38٪ قیمت) | RSI(14): 61
EMA9: 100,050 | EMA21: 99,880 | سقف ۲۲ کندله: 100,100
```

محاسبه:
```
movePct      = (100350−99200)/99200×100 = +1.15٪  → ≥0.45 → خرید +24
oneCandlePct = +0.45٪                            → ≥0.3  → +12
volX         = 850/400 = 2.13                    → ≥1.8  → +22
شکست سقف     = 100350 > 100100                   → TRUE  → +22
روند         = ۵ صعودی از ۷ کندل آخر             → TRUE  → +10
RSI = 61                                       → بین 35 و 65 → 0
EMA9 > EMA21                                   → TRUE  → +8
بدنه = 0.30٪ > 0.35×0.38٪=0.13٪ و صعودی         → +10
ATR٪ = 0.38 ≥ 0.03                             → بدون جریمه
─────────────────────────────────────────────────────────
جمع خرید: 24+12+22+22+10+0+8+10 = 108
ریز‌کندل: ۳ کندل ۱m صعودی هم‌جهت → 108 × 1.15 = 124 → clamp → امتیاز 100
100 ≥ minScore(85) → سیگنال LONG ✅
```

پلن معامله:
```
فاصله استاپ = max(ATR×2.2=836 ، 0.15٪×قیمت=150) = 836
ورود  = 100350×(1+0.02٪ اسلیپیج) ≈ 100,370
استاپ = 100370−836 = 99,534   (−0.83٪)
حد سود = «باز» در حالت شناور — استاپ پشت سود بالا می‌رود
نوتسیونال = مارجین 40 × اهرم 5 = 200 USDT → ریسک ≈ 1.67 USDT + کارمزد
```

### فرمول‌ساز پارامتریک خودت (جای ورود به الگوریتم)
در تنظیمات، حالت `filter` را انتخاب کن و عبارت بنویس — سیستم هر اسکن با مقادیر واقعی بالا ارزیابی‌اش می‌کند:

```
متغیرها (۱۹ عدد): price, movePct, oneCandlePct, volX, atr, atrPct, rsi,
  emaFast, emaSlow, emaRatio, bodyPct, breakoutUp, breakoutDown,
  trendUp, trendDown, microStreak, microLong, microShort, hourUtc
عملگرها: + - * / % ^ ( ) < <= > >= == != && || ! ?:
توابع:  min() max() abs() clamp(x,lo,hi) if(cond,a,b) sign() round()
```
- نتیجه > 0 → ورود آزاد + پاداش امتیاز (`formulaBonusPct`)
- نتیجه ≤ 0 → ورود مسدود (علامت 🧮 روی کارت)
- خطای فرمول (تقسیم بر صفر، متغیر غلط) → خنثی + علت شفاف، هرگز کرش نه
- دکمهٔ «🧪 تست فرمول روی دیتای زندهٔ الان» نتیجه را همان لحظه نشان می‌دهد

**مثال‌ها:**
```
(rsi < 40 && volX > 1.4) || (rsi > 62 && movePct < -0.2)     ← فیلتر کلاسیک
clamp((volX - 1) * 20 + (40 - rsi), 0, 30)                    ← امتیاز پیوسته
if(emaFast > emaSlow, min(movePct * 25, 25), 0)               ← شرطی روند
hourUtc >= 12 && hourUtc <= 20 && breakoutUp                  ← فقط عصر + شکست
```

## ۲) 🎯 شرایط بستن معاملات — چک‌لیست کامل با پارامترها

هر اسکن، همهٔ پوزیشن‌ها به این ترتیب بررسی می‌شوند (اولین شرط برقرار می‌بندد):

| # | reason | شرط دقیق | پارامتر | TF-قفل؟ |
|---|---|---|---|---|
| ۰ | `MAX_HOLD_EXIT` | عمر ≥ حداکثر نگهداری | `maxHoldMinutes` | مستقل |
| ۱ | `SL_HARD_STOP` | قیمت/Low-High به استاپِ **زیر ورود** رسید | `atrStopMult` | مستقل (قیمتی) |
| ۱′ | `PROFIT_TRAIL_REVERSED` | استاپِ **بالای ورود** (بریک‌ایون/ترلینگ) لمس شد = بستن سود | — | مستقل (قیمتی) |
| ۲ | `TAKE_PROFIT` | فقط حالت `fixed`: رسیدن به takeProfitR | `profitMode='fixed'` | مستقل |
| ۳a | Breakeven | به‌محض سودشدن، استاپ → ورود+بافر (ریسک صفر) | `breakevenBufferPct` | مستقل |
| ۳b | `PROFIT_TRAIL_REVERSED` | استاپ = قلهٔ سود − trailAtrMult×ATR؛ فقط بالا می‌رود | `trailAtrMult` | 🔒 فقط ATR هم‌تایم |
| ۳c | `REVERSAL_RSI_*` | RSI اشباع مخالف + شروع حرکت مخالف | `reversalRsiHigh/Low`, `reversalMovePct` | 🔒 |
| ۳c | `REVERSAL_EMA_CROSS` | کراس EMA9/21 مخالف + جهش حجم | `reversalVolX` | 🔒 |
| ۳d | `MOMENTUM_FADE` | N کندل بستهٔ مخالف پی‌درپی = «نمودار برای حرکت کمتر شد» | `fadeCandles` | 🔒 |
| ۴ | `TREND_FLIP` | سیگنال مخالف با امتیاز ≥ minScore → تز باطل، حتی در ضرر | `minScore` | 🔒 |

🔒 = فقط با تایم‌فریم ورود؛ اگر تنظیمات وسط معامله عوض شده باشد قفل می‌شوند.

### منطق «سود شناور تا اوج» (درخواست تو — `profitMode: float`)
1. حد سود **باز** است؛ قیمت هرچقدر برود، `highWater` (اوج سود) ثبت می‌شود.
2. استاپ مثل قطار پشت قله کشیده می‌شود: `استاپ = highWater − 1.25×ATR` — فقط بالا می‌رود.
3. معامله فقط با «سیگنال تغییر روند» بسته می‌شود: برگشت به ترلینگ / چرخش RSI / کراس EMA / محو مومنتوم / سیگنال مخالف قوی.
4. بعد از هر خروج، `peakPnl` و `givebackPct` ثبت می‌شود تا ببینی چقدر از اوج گرفتی و چقدر پس دادی → ابزار تنظیم `trailAtrMult`.
5. ضرر اما قاطع است: SL هیچ‌وقت عقب نمی‌رود + TREND_FLIP حتی پوزیشن ضررده را با سیگنال مخالف قوی می‌بندد.
