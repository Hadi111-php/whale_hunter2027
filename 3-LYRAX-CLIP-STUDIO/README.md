# 🎬 سیستم حرفه‌ای، پارامتریک و ماژولار ساخت کلیپ (Clip Maker Studio)

این پروژه یک ویرایشگر ویدیویی تحت وب با معماری ماژولار و شیءگرا است که دقیقاً بر اساس سناریو و روش کاری اختصاصی شما طراحی و ساخته شده است.

---

## ✨ قابلیت‌های کلیدی سیستم

1. **مدیریت پوشه پروژه و فایل‌ها**: انتخاب نام پروژه و ذخیره‌سازی ساختاریافته‌ی تمامی فایل‌های صوتی (MP3, WAV)، ویدیویی (MP4)، تصاویر (JPG/PNG) و متن‌ها درون فولدر اختصاصی `projects/project_name/`.
2. **همگام‌سازی تعاملی لیریکس (Tap to Sync)**: 
   - برای اشعار بدون تایم‌استمپ، کافی است متن کامل را پیست کنید.
   - هنگام پخش موزیک، با هر بار کلیک روی دکمه **«ثبت زمان و خط بعدی ⏭️»**، زمان دقیق پایان جمله قبل و شروع جمله جدید در لحظه ثبت می‌شود.
   - امکان بازگشت و اصلاح با دکمه **«خط قبلی ⏮️»**.
3. **جدول پارامتریک مختصات و زمان‌بندی**:
   - تنظیم دقیق زمان شروع (`start_time`) و پایان (`end_time`).
   - پشتیبانی هم‌زمان از واحد **درصد (%)** و **پیکسل (px)** برای موقعیت و ابعاد (مانند `x: 10%`, `width: 80%`).
4. **ذخیره و بازیابی پروژه بصورت JSON**: ذخیره کامل سناریو در فایل `project.json` درون فولدر پروژه جهت ویرایش‌های بعدی بدون نیاز به شروع از صفر.
5. **دو موتور رندر قدرتمند در بک‌اند**:
   - **موتور FFmpeg CLI (پیشنهادی)**: سرعت رندر خیره‌کننده، تولید زیرنویس ASS با فونت Vazir، رنگ لیمویی (`#FFF000`) و حاشیه مشکی (`#000000`).
   - **موتور MoviePy**: پردازش فریم به فریم پایتونی با رندر دقیق تایپوگرافی فارسی.
6. **اسکریپت مستقل شل (`render.sh`)**: رندر سریع پروژه در محیط‌های سروری یا ترمینال بدون نیاز به اجرای وب‌سرویس.

## 📂 ساختار ماژولار پروژه

```text
clip_maker/
├── app.py                     # بک‌اند وب با Flask
├── render.sh                  # اسکریپت اجرای مستقل FFmpeg در ترمینال
├── requirements.txt           # وابستگی‌های پایتون
├── projects/                  # محل ذخیره پروژه‌ها و سناریوهای JSON
│   └── sample_clip/           # پروژه نمونه آماده
├── static/
│   ├── css/style.css          # استایل مدرن تاریک با تم لیمویی
│   ├── fonts/Vazirmatn.ttf    # فونت فارسی وزیرمتن
│   └── js/
│       ├── app.js             # کنترلر اصلی برنامه
│       ├── modules/
│       │   ├── Event.js       # مدل رویداد و مختصات
│       │   ├── Timeline.js    # موتور مدیریت تایم‌لاین
│       │   ├── Project.js     # مدیریت وضعیت و خروجی JSON
│       │   ├── MediaController.js # همگام‌ساز پلیر صوتی/تصویری
│       │   └── EventFactory.js # کارخانه ساخت رویدادهای استاندارد
│       ├── handlers/
│       │   ├── LineHandler.js # رکوردر تعاملی خط به خط لیریکس
│       │   └── RenderHandler.js # ارتباط با API و مانیتورینگ پیشرفت
│       └── ui/                # کامپوننت‌های رابط کاربری (PlayerUI, EventListUI, LyricsUI)
└── templates/
    └── index.html             # رابط کاربری وب (Single Page)
```

## 🚀 راهنمای اجرا

### روش اول: اجرای وب‌سرویس (Flask)

۱. نصب کتابخانه‌های مورد نیاز:
```bash
pip install -r requirements.txt
```

۲. اجرای بک‌اند پایتون:
```bash
python app.py
```

۳. باز کردن مرورگر و ورود به آدرس:
```text
http://localhost:5000
```

---

### روش دوم: رندر مستقیم در ترمینال با اسکریپت شل

اگر فایل سناریو `project.json` و مدیاها را در فولدر پروژه دارید، می‌توانید بدون باز کردن مرورگر خروجی بگیرید:

```bash
chmod +x render.sh
./render.sh projects/sample_clip
```

## 💡 نکات طراحی خروجی عمودی (1080x1920)

- رزولوشن خروجی به طور پیش‌فرض روی **۹:۱۶ (عمودی ۱۰۸۰ در ۱۹۲۰)** تنظیم شده که برای ریلز اینستاگرام، یوتیوب شورتز و تیک‌تاک ایده‌آل است.
- تمامی لیریکس‌ها با رنگ لیمویی زنده (`#FFF000`) و حاشیه مشکی ضخیم رندر می‌شوند تا روی هر پس‌زمینه‌ای کاملاً خوانا باشند.
- هنگام اتمام رندر در مرورگر، دانلود فایل خروجی `MP4` به طور خودکار آغاز می‌شود.
