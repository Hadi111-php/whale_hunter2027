# راهنمای بسته‌ی کامل پروژه

## محتوای این بسته
- `studio.html` — فایل اصلی ادیتور کلیپ (منبع اصلی برای ویرایش). آخرین ویژگی‌ها:
  - رعدوبرق سه‌تیره (معمولی/کلفت‌تر/قوی و پیچیده با شاخه‌ی فرعی)، هم‌راستا با انرژی زنده‌ی آهنگ (مثل اکولایزر)
  - رعدوبرق با سه روش تریگر: تشخیص خودکار ضرب، فاصله‌ی زمانی ثابت (برای آهنگ‌های آرام)، یا دکمه‌ی دستی
  - واترمارک/امضای شخصی سه‌بعدی و چرخشی: ورود چرخشی از یک‌طرف، توقف کامل وسط کلیپ، خروج چرخشی نزدیک پایان که دقیقاً هم‌زمان با پایان آهنگ محو می‌شود
  - بهینه‌سازی کاراُوکه با کش تصویری (سریع‌تر روی گوشی‌های ضعیف)
- `templates/index.html` — کپی همگام‌شده‌ی `studio.html` (سرو می‌شود توسط Flask)
- `backend/` — منطق رندر نهایی (FFmpeg + ASS)، دقیقاً هماهنگ با پیش‌نمایش مرورگر
- `app.py`, `render.sh`, `requirements.txt` — راه‌اندازی سرور Flask
- `secure_wake_prototype/` — پروژه‌ی امنیتی «چشم‌ودست» (Secure Wake) با پلتفرم چندکاربره
- `skyground_project/` — عامل هوش مصنوعی محلی SkyGround
- `android-app/`, `android-apk-output/` — نسخه‌ی اندروید (ممکن است نیاز به بازسازی با آخرین `studio.html` داشته باشد)

## نحوه‌ی اجرا
```
pip install -r requirements.txt
python3 app.py
```
سپس در مرورگر به `http://localhost:5000` بروید. **هرگز فایل `studio.html` را مستقیم دبل‌کلیک نکنید** — چون بدون سرور، پخش صدا و تحلیل صوتی کار نمی‌کند.

## نکته‌ی مهم درباره‌ی APK اندروید
اگر پوشه‌ی `android-apk-output` را ببینید، ممکن است از نسخه‌ی قدیمی‌تر `studio.html` ساخته شده باشد (پیش از رعدوبرق سه‌تیره یا واترمارک سه‌بعدی). برای بازسازی با آخرین تغییرات، باید با Gradle دوباره ساخته شود.
