# 🎵 ClipStudio (یا نام واقعی اپلیکیشن لیریکس شما)

یک اپلیکیشن لیریکس (متن آهنگ) حرفه‌ای، دوزبانه و با تجربه‌ی کاربری روان که امکان نمایش همزمان متن اصلی و ترجمه را با سینک (Sync) دقیق فراهم می‌کند.

## ✨ ویژگی‌های کلیدی
- 🌍 **پشتیبانی کامل دوزبانه**: نمایش همزمان متن اصلی و ترجمه با فرمت استاندارد.
- ⏱️ **سینک دقیق زمانی**: پشتیبانی از فرمت `.lrc` و اسکرول خودکار نرم (Smooth Scroll).
- 🎨 **رابط کاربری مدرن**: پشتیبانی از حالت تاریک (Dark Mode) و قابلیت تغییر سایز فونت.
- ⚡ **سبک و بهینه**: استفاده از معماری بهینه برای اجرای روان حتی در آهنگ‌های با لیریکس طولانی.

## 🚀 نصب و راه‌اندازی
(در اینجا توضیح بده چطور پروژه اجرا میشه. مثال:)
1. مخزن را کلون کنید: `git clone https://github.com/HaadiTaba111/clipStudio.git`
2. وارد پوشه پروژه شوید: `cd clipStudio`
3. وابستگی‌ها را نصب کنید: `npm install` (یا دستور مربوط به فریم‌ورک شما)
4. پروژه را اجرا کنید: `npm start`

## 📂 ساختار پروژه
- `clip_studio_package/`: هسته‌ی اصلی پردازش و پارس کردن فایل‌های لیریکس.
- `assets/`: فایل‌های استاتیک و منابع.
- `src/`: کدهای اصلی رابط کاربری و منطق برنامه.
